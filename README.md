# Casher

Casher is a frontend architecture showcase built with Vue.

This project intentionally adopts architectural decisions designed for a much larger application than its current scope. The goal is to demonstrate frontend engineering practices focused on scalability, maintainability and codebase quality rather than building the simplest possible implementation.

Many of the decisions in this repository prioritize **clear separation of concerns, component isolation and long-term maintainability**, even when they might seem excessive for a small project.
